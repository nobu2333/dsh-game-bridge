> 日期：2026-10-30 · 状态：讨论稿（Lead 整理）

## 1. 目标

插件要做的事可以收敛成两件：

1. **看得懂游戏**：把画面变成**实体级、可行动**的状态（玩家/敌人/弹幕/地形/UI/场景），而不是像素统计；
2. **会玩**：在本地闭环里拥有**技能库 + 战术选择 + 战略路线**，模型只负责高层目标。

验收标准以「游戏内结果」为准：受击次数、死亡次数、卡住秒数、关卡进度、首次通关时间；不再以「按了多少键 / 工具调用次数」衡量。

---

## 2. 现状诊断（Cuphead 实测）

### 2.1 已经做到的

- 抓屏 / OCR / 窗口裁剪 / 前台与遮挡检测稳定；
- 60 Hz 策略循环可达 **58 Hz（无跟踪）/ 52.7 Hz（带跟踪）**；
- 玩家模板追踪在已保存关卡帧上匹配分数 0.97 / 0.72，坐标正确；
- 镜头滚动（phase correlation）用于「是否在前进」，卡住脱困可触发；
- 场景/HP/提示的文字版 WorldState 已可用；
- 三层架构（引擎 / 插件 / profile 数据）与安全闸已就位。

### 2.2 未通关的根因（按重要性）

| # | 根因 | 证据 |
|:--|:--|:--|
| 1 | **感知不是实体级**：威胁只是相邻帧运动簇，没有 ID、类型、速度、相对方向 | 只会「看到在动」，不知道背后有敌人、不知道子弹朝哪飞 |
| 2 | **策略只有「前进 + 射击」**：不会转身、不会后退、不会选目标、不会利用地形 | 一直 hold RIGHT+X，周期性盲跳；贴着敌人走进伤害 |
| 3 | **场景状态机缺失**：死亡/换装卡界面不认识，按错键（SHIFT 打开 Equip Card） | 多次卡在 Equip Card/DEAD，整轮重试作废 |
| 4 | **交互提示只做 OCR 文字**：黑底 Z / 按键图标检测不到 | 站在入口提示下，`game_state.prompt=None` |
| 5 | **没有关卡地图/记忆/复盘**：每次重试重复同样错误，找入口靠截图试探 | 世界地图来回走、过冲、绕圈 |
| 6 | **性能与观测预算仍有压力**：带跟踪时 52.7Hz，关卡内实测 ~35Hz；OCR 无法进高频环 | 多速率架构未落地，慢通道未异步化 |
| 7 | **失败保护不足**：感知不确定时仍然继续输出，导致「无脑冲」 | 威胁误检/漏检时没有减速/撤退 |

**一句话**：现在只有「眼睛的毛坯 + 一条前进循环」，缺「理解层」和「技能层」。

## 3. 目标架构

```
┌────────────────────────────── 感知层（多速率） ─────────────────────────────┐
│ 60Hz: 抓屏 → 玩家追踪/实体跟踪/弹幕/ego-motion → 实体级 WorldState v2         │
│ 2–5Hz: OCR / 场景分类 / UI 提示 / HUD / 交互图标（异步，不阻塞 60Hz）         │
│ 事件: 死亡/换装/菜单/关卡边界 → 场景状态机                                   │
└───────────────────────────────────┬──────────────────────────────────────────┘
                                    ▼
┌────────────────────────────── 决策层（分层） ───────────────────────────────┐
│ 技能层 60Hz: face/shoot_at/dodge/jump_over/retreat/parry/hold_position       │
│ 战术层 1–5Hz: 选目标 / 选姿态（推进/清场/后撤/绕路）/ 换武器 / 用技能         │
│ 战略层 事件驱动: 关卡路线 / Boss 阶段 / 资源 / 复盘                           │
└───────────────────────────────────┬──────────────────────────────────────────┘
                                    ▼
┌────────────────────────────── 执行层（已有） ───────────────────────────────┐
│ 键鼠/手柄注入 · 焦点管理 · 安全闸 · 审计                                     │
└─────────────────────────────────────────────────────────────────────────────┘
                                    ▲
┌────────────────────────────── 记忆与档案（数据） ───────────────────────────┐
│ GameProfile: 控制/HUD/颜色/模板/场景关键词/技能参数                          │
│ Map: 节点/边/入口/地标/可达关系 · Attempt: 局记录/死亡复盘/模板库            │
└─────────────────────────────────────────────────────────────────────────────┘
```

原则：

1. **模型不进入 60Hz 环**：模型只读结构化状态，0.5–2Hz 做战术/战略；
2. **视觉是保底地板**：任何游戏即使没有模板/内存也能观察和做基础动作；
3. **L2 状态源（内存/API/模组）是可选加速器**：按游戏接入、只读、反作弊禁用；
4. **不确定就停/退**：感知置信度低时禁止盲目前进。

## 4. WorldState v2（实体级 schema）

```json
{
  "schema": 2,
  "t": 1793339251.698,
  "scene": {"state": "gameplay", "confidence": 0.93},
  "player": {
    "x": 0.33, "y": 0.79, "vx": 0.0, "vy": 0.0,
    "facing": "right", "grounded": true,
    "hp": 3, "max_hp": 3, "invincible": false,
    "action": "idle|run|jump|dash|shoot|parry|hit|unknown",
    "confidence": 0.97
  },
  "entities": [
    {"id": "e12", "kind": "enemy", "sprite": "flower", "x": 0.62, "y": 0.71,
     "vx": -0.03, "vy": 0.0, "hp": null, "threat": 0.8,
     "relation": "ahead", "confidence": 0.8},
    {"id": "p7", "kind": "projectile", "x": 0.5, "y": 0.3,
     "vx": -0.2, "vy": 0.1, "time_to_hit": 0.35, "threat": 0.9}
  ],
  "world": {"scroll_dx": 1.8, "ground_y": 0.82, "hazards": [], "platforms": []},
  "ui": {"prompt": {"type": "confirm", "key": "Z", "text": null},
          "menu": {"highlight": 2, "options": ["RETRY", "EXIT TO MAP"]}},
  "game": {"profile": "cuphead", "providers": ["vision"], "stale": false}
}
```

要求：

- 所有字段带 confidence/stale；实体有稳定 ID（跨帧跟踪）；
- 坐标归一化；未知字段允许 null；
- 高频字段（玩家/实体）走 60Hz，低置信度必须显式；
- OCR/UI 字段异步更新，带时间戳，不阻塞高频环。

## 5. 感知层设计（P0）

### 5.1 玩家追踪（已有基础，需补状态）

- 模板/颜色追踪保留；补充：
  - 朝向：模板左右翻转匹配 / 运动方向；
  - 动作：跳跃/冲刺/射击用帧差与模板组合判断；
  - 落地/平台：脚底以下像素 + 垂直速度；
  - 无敌帧：周期性闪烁/HP 变化事件；
- 丢失重捕获：局部搜索 → 全屏 → 保持最后状态并降置信度，**不硬猜**。

### 5.2 实体跟踪（最关键）

- 检测器两级：
  1. **通用**：运动簇 / 边缘 / 颜色（当前 threat 检测升级为带跟踪）；
  2. **模板库**：profile 提供敌人/道具/图标模板（PNG base64），多尺度匹配；
- 关联：IOU + 位置预测（Kalman/简单线性），分配稳定 ID；
- 输出：类型、位置、速度、相对玩家方向（前/后/上/下）、威胁分（距离 + 速度朝玩家 + 预计命中时间）；
- 模板库可**自动积累**：从录像帧里裁剪高分候选，人工确认后入 profile（降低每游戏配置成本）。

### 5.3 弹幕/危险物

- 复用实体跟踪，kind=projectile；估计 `time_to_hit`；
- 优先级：即将命中 > 正在靠近 > 静止危险。

### 5.4 场景与 UI

- 场景分类：`menu/gameplay/cutscene/death/equip/pause/loading`，融合 OCR 关键词、黑屏、HP 区、模板；
- 交互提示：**文字 + 按键图标**双通道（黑底 Z、A/B 图标、CONFIRM/PRESS 等词）；
- 菜单高亮/选项：模板或颜色边框；
- HUD：HP/金币/大招条区域自动发现 + OCR/颜色读取。

### 5.5 地形与地图

- 局部可通行图：地面/平台/坑/墙，来自颜色/边缘 + 动作探测（走过去画面是否变化）；
- ego-motion/scroll：已有，扩展为局部平移估计，支撑地图拼接；
- 世界地图：landmark（signpost/商店/桥/房子）检测 + 拓扑图；
- **入口触发圈 = 交互提示出现的位置**（通用信号），不依赖识图。

### 5.6 多速率调度

- 60Hz：抓屏 + 玩家/实体跟踪（轻量模板/颜色/光流）；
- 2–5Hz：OCR、场景、提示、HUD（后台线程，写缓存 WorldState）；
- 慢通道结果带时间戳，60Hz 只消费最新值；
- 预算：高频环 ≤ 10–12ms/拍，目标 50–60Hz。

## 6. 决策层设计（P1）

### 6.1 技能库（60Hz）

```text
face(direction)                      # 转身
shoot_at(target_id | direction)      # 朝目标/方向射击
dodge(entity_id)                     # 按预计命中方向跳/冲刺/侧移
jump_over(entity_id | pit)           # 越过敌人/坑
retreat(duration_ms)                 # 后撤拉开
keep_distance(target_id, range)      # 保持距离
parry(entity_id)                     # 粉球格挡
hold_position()                      # 停火/等待
```

技能必须基于实体状态和预测，不允许「固定间隔盲跳」这种伪技能。

### 6.2 战术选择器（1–5Hz）

输入：WorldState v2；
输出：目标 + 姿态 + 期望方向 + 是否用资源。

规则（可先规则，后模型）：

- 有即将命中的弹幕 → `dodge`；
- 有背后靠近的敌人 → `face` + `shoot_at` 或 `retreat`；
- 前方有敌群 → 停步清场（`hold_position` + `shoot_at`），清完再前进；
- 血量低 → 后撤/保守，避免接触；
- 有坑/平台 → 选择跳跃/绕行；
- 无威胁 → 推进/探索。

### 6.3 场景状态机

```text
menu → gameplay → (death → retry) | (cutscene → skip) | (equip → back) | (pause → resume)
```

每个状态声明允许的动作与确认键；**死亡/换装卡必须有恢复路径**，否则整轮尝试无效。

### 6.4 失败保护

- 感知置信度低 / 玩家丢失 / 遮挡 → 停止前进、降速、重新感知；
- 连续无位移/无进度 → 探测绕行；
- 进入未知场景 → 先用低风险动作试探。

## 7. 记忆与学习（P1–P2）

### 7.1 GameProfile（数据）

在现有 controls/hud/scene/combat/colors 基础上增加：

- `player`: 模板、颜色、尺寸比例、跟踪参数；
- `entities`: 敌人/道具/图标模板库与阈值；
- `skills`: 技能参数（射击距离、闪避预测窗口、跳跃时机）；
- `map`: 节点/边/入口/地标/可达关系；
- `knowledge`: 敌人攻击模式、Boss 阶段、安全点（带来源/置信度）；
- `notes`: 人工备注。

### 7.2 尝试记录与死亡复盘

- 每局记录：关键帧（10–15Hz 缩略图）、WorldState、输入、事件；
- 死亡时保存最近 15 秒环形缓冲 + 死因猜想（受击来源、位置、HP 变化）；
- 用复盘调阈值/技能参数；后续可做行为克隆/小型策略学习。

### 7.3 地图记忆

- 首次探索自动建图（节点=地标/入口，边=可走路径）；
- 重复游玩直接复用路线；
- 回环检测修正漂移；
- 用户可查看/修正。

## 9. 路线图与验收

### P0（先让「看得懂」成立，约 3–5 个迭代）

1. WorldState v2 + 实体跟踪 ID（敌人/弹幕/玩家状态）；
2. 交互提示图标检测 + 场景状态机（menu/death/equip）；
3. 地形/地面/坑检测 + ego-motion 进度；
4. 60Hz 预算达标（≥50Hz），OCR 异步化；
5. 失败保护（低置信度停/退）。

**验收**：Cuphead 关卡内「60 秒不因撞怪掉血」；死亡/换装卡不再卡死；入口提示识别率 ≥90%。

### P1（让「会玩」成立）

1. 技能库（转身/射击/闪避/跳越/后撤/保持距离）；
2. 战术选择器（目标/姿态/方向）；
3. 世界地图 landmark + 闭环导航（走到入口 → 确认）；
4. 死亡复盘/尝试记录。

**验收**：Forest Follies 稳定到达中段/终点；失败后能自动重试；卡住秒数显著下降。

### P2（稳定通关与泛化）

1. 地图记忆与路线复用；
2. 敌人/Boss 知识档案；
3. 游戏矩阵评测（10–20 款不同引擎/品类）；
4. 可选 L2 状态源 + 模板自动积累。

**验收**：Cuphead 第一关通关（多次稳定）；游戏矩阵中「可观察/可过菜单/可基础游玩」覆盖率与人工配置量达标。

## 10. 评测指标

| 指标 | 说明 | 目标 |
|:--|:--|:--|
| 感知：玩家位置误差 | 与人工标注/内存真值对比 | < 3% 画面宽 |
| 感知：提示召回率 | 交互提示出现时被识别 | ≥ 90% |
| 感知：实体召回/精度 | 敌人/弹幕跟踪 | 先 70%/80%，逐步提高 |
| 行为：受击/分钟 | 关卡内 | 持续下降 |
| 行为：死亡次数/尝试 | 同关卡 | 持续下降 |
| 行为：卡住秒数 | 无进度时间 | < 5s/次 |
| 结果：进度/通关 | 关卡完成度 | Forest Follies 通关 |
| 成本：模型调用/分钟 | 高频环不进模型 | 目标 ≤ 10 |
| 泛化：每游戏人工配置 | profile 条目/模板数 | 持续下降 |

## 11. 工程与测试

- 单元测试：感知合成帧（玩家/实体/提示/场景）、技能前置条件、状态机转移、失败保护；
- 集成测试：真实抓屏 + 假控制器；新增 `game_state_v2` 契约用例；
- 性能基准：高频环 p50/p90 耗时、跟踪开销、OCR 异步延迟；
- 回放工具：用保存的帧序列离线重跑策略，确定性对比；
- 文档：公开仓库只放 schema/接口/安全说明；本文件与游戏模板、实测数据留在本地。

## 12. 公开仓库与合规

- 不提交：游戏精灵模板、具体游戏 offset/破解数据、本机路径、游玩录像；
- 反作弊游戏：只读都不接，直接拒绝；
- 内存/模组路径：必须显式用户同意、只读、单机、默认关闭；
- README/市场口径同步：视觉保底 + 可选 L2，不承诺「大部分游戏能读接口」。

---

## 13. 风险与未决

1. 视觉实体检测在低对比度/密集弹幕下召回不足 → 依赖模板库/多帧跟踪；
2. 每游戏模板/参数仍有配置成本 → 需要自动积累与社区共享机制；
3. 地图拼接漂移与遮挡 → 需要回环检测和人工可修正；
4. 60Hz 与 OCR 异步的线程安全/延迟 → 需要缓存与版本号；
5. Cuphead Equip Card 这种游戏内 modal 输入 bug → 需要状态机 + 重启恢复；
6. 内存读取的合规/市场风险 → 保持可选与本地化。

## 14. 模块落点（建议）

- `engine/dsh_game_core/state.py`：WorldState v2、玩家/实体/场景/提示/地形；
- `engine/dsh_game_core/tracking.py`（新）：实体跟踪/关联/轨迹；
- `engine/dsh_game_core/policy.py`：技能库 + 战术选择器 + 状态机 + 失败保护；
- `engine/dsh_game_core/engine.py`：多速率抓帧、异步 OCR 缓存；
- `lib/index.js`：`game_state` v2 输出、`game_policy` 技能/目标参数、`game_memory` 模板/地图；
- `profiles/*.json`：玩家/敌人模板、场景关键词、地图、技能参数；
- `docs/`：只保留公开 schema 与安全说明（本文件不入库）。
